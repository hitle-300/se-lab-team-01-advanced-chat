# ملخص المشروع (Project Brief)

## اسم المشروع
نظام المحادثة وإدارة الشبكات الشامل (Advanced Chat System)

## المشكلة
تشتت بيانات فرق العمل والطلاب بين منصات خارجية غير آمنة ومفتقرة للخصوصية، وصعوبة تبادل الملفات الضخمة داخل الشبكة المحلية بدون اتصال بالإنترنت، بالإضافة إلى انعدام رقابة الإدارة على الاتصالات.

## الحل المقترح
بناء نظام متكامل بلغة Flutter ينقسم إلى:
1. **تطبيق عميل (Client):** للدردشة ونقل الملفات.
2. **تطبيق خادم (Server):** لإدارة الاتصالات (TCP Sockets) وتخزين البيانات باستخدام SQLite، مع لوحة تحكم إدارية.

## القيمة المضافة
توفير منصة تواصل موحدة وسريعة جداً وآمنة للبيئات المؤسسية المغلقة (LAN)، مما يضمن بقاء البيانات المهمة داخل جدران المؤسسة.
