# نظام المحادثة ونقل الملفات المتقدم (Advanced Chat System)

## وصف مختصر
نظام مبني بنمط العميل والخادم (Client/Server) يحل مشكلة تشتت تبادل البيانات ويوفر بيئة آمنة للمحادثات الفورية ونقل الملفات الضخمة والصوتيات داخل الشبكات بخصوصية تامة.

## أعضاء الفريق
- الطالب :محمد صادق الحضرمي 
- الطالب : زياد السماوي
- الطالب : امجد السماوي

## التقنيات المتوقعة
- Flutter / Dart
- SQLite (عبر sqflite_common_ffi)
- Git & GitHub
- Markdown (للتوثيق)
