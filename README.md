# نظام المحادثة وإدارة الشبكات الشامل (Advanced Chat System)

## وصف المشروع

نظام متكامل مبني بنمط العميل والخادم (Client/Server) باستخدام Flutter، يوفر بيئة آمنة للمحادثات الفورية، وإرسال الملفات الضخمة، والرسائل الصوتية داخل الشبكات المحلية بخصوصية تامة دون الحاجة لخوادم سحابية.

## المشكلة

تحتاج المؤسسات وفرق العمل إلى بيئة تواصل داخلية (Local/Private Network) تضمن سرية المحادثات وتبادل الملفات الكبيرة. التطبيقات التقليدية تفتقر إلى أدوات رقابة مركزية تمنح الإدارة القدرة على تتبع الجلسات بفعالية، وتعتمد على خوادم خارجية قد تنتهك الخصوصية.

## المستخدمون المستهدفون

- الطالب / الموظف (Client)
- مشرف النظام (Admin)
